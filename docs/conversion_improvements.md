# 変換結果改善と実ファイルの比較

## 原因と変更

実ファイルの本文直下には10表があり、列見出しを除く職歴行は17件だった。
表1に見出しがあり、ベルティスの後続業務は見出しのない表2・表3へ分割されていた。
既存実装は表ごとに見出しを要求していたため、この2表を対象外にしていた。

前表と直接隣接し、同じ列数で、各行に明示的な期間と内容の節見出しがある場合のみ
前表の列構成を引き継ぐように修正した。引き継ぎは警告する。
会社見出しや空段落を含む別の要素を挟む場合、未知の内容、結合・列数不一致は自動補完しない。

## 修正前後の確認

| 確認項目 | 修正前 | 修正後 |
| --- | --- | --- |
| 抽出件数 | 15件 | 17件 |
| 本文表内の職歴行との対応 | 15/17行 | 17/17行 |
| 2025年11月～2026年1月の業務 | 対象外 | 表2 行1として抽出 |
| 2026年2月～8月の総務人事 | 対象外 | 表3 行1として抽出 |
| 経理事務・農業 | 抽出済み | 維持 |
| 期間 | 複数行 | 年月・月数・注記を保持して1行 |
| 説明と工程 | 同じ欄に連結 | 担当業務と担当工程に分離 |
| 技術要素 | 複数行 | 順序・重複を保ち「、」で連結 |

既存15件は案件名と期間の組み合わせで照合した。同名の別期間案件を区別し、
概要と担当業務の文字列、年月・記載月数、技術要素が保持されていることを確認した。
担当業務は説明と工程を元の順番で連結すると既存出力に一致することを確認した。
期間の月数は計算しない。原文にある【成果】や注記も保持する。

元Wordは比較前後のSHA-256が一致した。既存の変換結果も変更せず、
改善後の実データのテキストファイルは保存していない。保存は利用者による全文確認とyes承認後に実行する。
実ファイルや個人情報をこのプロジェクトへコピーしていない。
マスク関数と設定読み込み関数は変更前後のソース一致を確認した。

今回の17/17件の確認範囲は、この文書の本文直下の表にある職歴行。
別文書の図形・画像・本文表外や未知の表構造までの完全な抽出を保証するものではない。

## 出力対象の選択案

全職種を対象とする現行動作を維持する。
必要になった場合は、推測によるIT／非IT判定ではなく、表番号・行番号を一覧表示して
対象を明示選択する方式が適切。今回の最小修正には選択機能を追加していない。
